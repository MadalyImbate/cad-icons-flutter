# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0

- Initial release on pub.dev.
- Added 250+ technical CAD vector icons.
- Built-in `ToolBarIcons` widget and `CadIcon` alias with full `IconTheme` compatibility.
- Remote hover previews in VS Code, Android Studio, and pub.dev documentation.
- Integrated web catalog for online search and previews.
