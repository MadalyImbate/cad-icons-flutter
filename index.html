Como usar o package no seu Projeto Flutter

1

Instalar o pacote via pub.dev

No terminal do seu projeto Flutter, execute:

flutter pub add cad_icons_flutter

Ou adicione no seu pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  cad_icons_flutter: ^1.0.0
2

Zero configuração de assets!

Você não precisa copiar pastas de ícones nem declarar assets: no seu pubspec.yaml. Os 250+ ícones já vêm empacotados dentro do pacote!

3

Usar em qualquer Widget com suporte a IconTheme

Importe e use os ícones nativamente com CadIcons(CadIcon...):

import 'package:cad_icons_flutter/cad_icons_flutter.dart';

// Uso direto:
CadIcons(CadIcon.draw3dCube)

// Com tamanho e cor personalizados:
CadIcons(
  CadIcon.threeDPrint,
  size: 32,
  color: Colors.blueAccent,
)

// Em botões e Toolbars (herda cores do IconTheme automaticamente):
IconButton(
  icon: const CadIcons(CadIcon.modify3dExtrude),
  onPressed: () {},
)
