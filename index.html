Como usar no seu projeto Flutter

1

Adicione o pacote ao seu projeto

flutter pub add cad_icons_flutter
2

Importe e utilize diretamente

import 'package:cad_icons_flutter/cad_icons_flutter.dart';

// Uso simples:
CadIcons(CadIcon.draw3dCube)

// Com customização ou em botões:
IconButton(
  icon: const CadIcons(
    CadIcon.threeDPrint,
    size: 28,
    color: Colors.blueAccent,
  ),
  onPressed: () {},
)
